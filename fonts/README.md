# Local font files

Only place legally testable font binaries here. Prefer WOFF2 for browser use.

For every binary:

- keep its license or attribution file beside it when required;
- add a complete record to `../metadata.json`;
- set `binaryDownloaded` to `true`;
- set `localFontPath` to a path relative to the lab, such as `fonts/family-regular.woff2`;
- record separate desktop, web, app, and commercial restrictions in `permissions`.

Paid, trial-only, personal-use-only, restricted, or unclear candidates belong in metadata as references without a bundled binary.
